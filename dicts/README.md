# YAML词典生成工具

```text
./
├ data/					# 原始数据
│	├ get_wordfreq.py	# 导出wordfreq中英文词频
│	├ zh/				# 中文数据
│	└ en/				# 英文数据
└ src/
	├ main.rs
	├ prelude.rs		# 自定义类型、编码节点与通用读取函数
	├ zh_chars.rs		# 处理现行国标通用规范汉字表和自定义加字
	├ pinyin.rs			# 生成拼音反查节点，保留多音节空格和有序候选
	├ tiger_dict.rs		# 单字选码、候选排序、消除空心节点，最后重编码
	├ zh_dict.rs		# 保留全部中文候选及匹配、加词与自动词的边界
	├ en_dict.rs		# 按前缀保存英文候选，单独记录prepend边界
	├ zh_en_dict.rs		# 合并中英文节点，按9格窗口编排候选
	└ lib.rs			# 按编码字典序遍历节点并输出YAML产物
```

主词典按每页9项编排：先排中文匹配和手工加词，首屏中文不足3项时用自动词补足，再连续排入全部英文prepend。后续窗口的前3格优先取中文自动词，后6格优先取英文候选及append；某一队列耗尽时，由另一队列补满。所有优先项都计入窗口位置，超过一页时连续跨页

中文自动词保留全部符合筛选条件的候选，跳过同码手工加词中已有的文本。各队列保持原有内部顺序，翻页继续消费剩余候选。纯英文编码保留原始Code首选
